# 개발 메모

## v0.2 — Android 앱의 현재 구현

- Android 8.0(API 26) 이상을 대상으로 하는 Java 네이티브 앱
- 기분 세 가지와 색감·스테이션·설명 전환
- 휴대폰에서 합성하는 기분별 배경음, 재생·멈추기, 초기 볼륨 20%
- 재생 상태에 따라 회전하는 레코드 그림
- 3·5·10분 프리셋과 1–60분 직접 입력, 일시정지·이어하기·다시 설정
- 종료 시각을 기준으로 앱 복귀 시 남은 시간을 갱신하는 타이머
- 화면 이탈과 오디오 포커스 상실 시 음악 정지
- 기분별 고정 문장 목록과 직전 문장의 연속 반복 방지
- 마지막 기분 저장과 화면 회전 시 화면·타이머 상태 복원
- 설치용 벡터 아이콘, 시스템 바·키보드 여백, 선택 상태와 입력 설명

API 35 환경에서 실행한 첫 화면을 [실행 캡처](images/android-preview.png)로 기록했다. [사용 장면 이미지](images/kitchen-mood-concept.png)는 생성한 콘셉트 이미지다. 두 이미지의 목적과 범위는 [사용 흐름](user-flow.md)에 설명한다.

## 먼저 확인할 사용성

| 항목 | 다음 확인 범위 |
| --- | --- |
| 실기기 오디오 | 스피커·유선 및 무선 이어폰에서 음량과 합성음 품질, 기분 전환 시 소리의 변화 |
| 오디오 포커스 | 통화·다른 음악 앱으로 포커스가 바뀔 때 정지와 수동 재생 흐름 |
| 타이머 | 일시정지·이어하기, 직접 입력 오류, 화면 복귀와 회전 중 남은 시간 표시 |
| 작은 화면과 접근성 | 큰 글꼴·화면 읽기에서 버튼 이름, 입력 라벨, 스크롤 조작 |
| 반복 사용 | 재생 버튼 발견, 시간 설정 실수, 문장과 배경음의 반복 부담 |

실기기 오디오 검증은 아직 완료하지 않았다. 이 목록은 후속 확인 계획이며 통과한 테스트 목록으로 해석하지 않는다.

## 다음 화면·콘텐츠 후보

- 사용자 선택에 따른 밝은 테마와 색상 조정
- 레코드 움직임을 끄는 옵션과 시스템 움직임 감소 설정 대응
- 기분별 화음 패턴과 짧은 문장 추가
- 시간대에 따른 스테이션 표시와 선택한 기분 기록

백그라운드 음악 재생, 타이머 알림·진동, 앱 종료나 휴대폰 재부팅을 넘는 타이머 지속은 현재 구현에 포함하지 않는다. 도입 여부는 실제 사용성 확인 뒤 결정한다. 현재 음악은 앱 화면이 활성화된 동안 재생하며, 시간과 기분은 사용자가 직접 선택한다.

## v0.1 — 브라우저 시제품

이전 브라우저 버전에는 세 가지 기분, 합성 배경음, 단일 타이머, 문장 전환과 마지막 기분 저장을 구현했다. 웹 소스는 저장소에 유지하고, 현재 Android 앱의 동작과 구분해 관리한다.

# 화면과 사용 흐름

## 사용 장면

저녁 준비를 시작한 사용자가 휴대폰을 주방 한쪽에 둔다. 오늘은 조금 느긋하게 보내고 싶어서 차분한 무드를 고른다. 라디오를 켜고, 필요한 시간을 5분으로 정한 뒤 조리를 시작한다.

![주방 사용 장면 콘셉트 스케치](images/kitchen-mood-concept.png)

*소리와 타이머를 주방에서 사용하는 장면의 콘셉트 스케치.*

## 화면 구성

| 영역 | 사용자가 하는 일 | 화면 반응 |
| --- | --- | --- |
| 오늘의 무드 | 기분 버튼 선택 | 색감·스테이션·한마디 변경 |
| 라디오 | 재생·정지, 볼륨 조절 | 재생 상태와 회전 레코드 표시 |
| 조리 타이머 | 시간 설정, 시작·정지·초기화 | 남은 시간과 상태 안내 |
| 오늘의 한 숟갈 | 다른 한마디 선택 | 현재 무드에 맞는 문구 변경 |

## 모바일

휴대폰에서는 무드 선택, 라디오, 타이머, 문구 카드를 위에서 아래로 쌓는다. 타이머 버튼을 누를 때 가로 스크롤 없이 조작할 수 있도록 구성한다.

## 데스크톱

기분 선택과 라디오를 첫 줄에 나란히 놓는다. 아래에는 타이머와 문구 카드를 배치한다. 큰 화면에서도 핵심 조작은 한 페이지에 유지한다.

## 접근성

현재 선택된 버튼은 눌림 상태를 표시한다. 버튼과 입력은 키보드로 이동할 수 있다. 타이머 완료와 주요 조작은 상태 안내로 전달한다. 움직임 감소 설정에서는 레코드와 막대 애니메이션을 멈춘다.

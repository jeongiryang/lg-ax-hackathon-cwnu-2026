# Kitchen Mood Radio 기획

## 선택 주제

Theme B — 새로운 키친 경험과 AI 기반 제품·서비스 설계

## 서비스 콘셉트

기분에 맞는 소리와 색감을 조합해 요리하는 시간을 조금 더 즐겁게 만드는 감성 Android 앱.

휴대폰에서 기분을 선택하고, 라디오와 직접 설정하는 타이머를 함께 사용한다. 식탁 준비부터 정리까지 자신의 분위기를 이어간다.

## 최소 기능

| 영역 | 내용 |
| --- | --- |
| 오늘의 무드 | 차분하게, 신나게, 집중해서 중 선택 |
| 라디오 | 합성 배경음, 스테이션 이름, 재생·정지, 볼륨 |
| 조리 시간 | 수동 단일 타이머, 프리셋, 일시정지·재개·초기화 |
| 한 문장 | 선택한 무드에 맞는 짧은 문구 |
| 설정 | 마지막 선택 무드 저장 |

## 구현

Java의 Android 플랫폼 View와 AudioTrack으로 구현한다. 소리와 시간을 기기 안에서 처리한다. 마지막 무드만 SharedPreferences에 저장한다. 화면 콘셉트를 먼저 확인한 웹 버전도 web 폴더에 남긴다.

## 사용성 확인

재생 버튼을 찾기 쉬운지, 타이머를 조작할 때 실수가 없는지, 배경음이 거슬리지 않는지 확인한다. 사용자가 직접 시간을 정하는 흐름을 유지한다.

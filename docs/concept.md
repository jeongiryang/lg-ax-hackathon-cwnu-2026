# Kitchen Mood Radio 기획

## 선택 주제

Theme B — 새로운 키친 경험과 AI 기반 제품·서비스 설계

## 서비스 콘셉트

기분에 맞는 소리와 색감을 조합해 요리하는 시간을 조금 더 즐겁게 만드는 감성 웹서비스.

주방에 둔 휴대폰에서 기분을 선택하고, 라디오와 타이머를 함께 사용한다. 식탁 준비부터 정리까지 자신의 분위기를 이어간다.

## 화면

| 영역 | 내용 |
| --- | --- |
| 오늘의 무드 | 차분하게, 신나게, 집중해서 중 선택 |
| 라디오 | 합성 배경음, 스테이션 이름, 재생·정지, 볼륨 |
| 조리 시간 | 분 단위 타이머, 프리셋, 일시정지·초기화 |
| 오늘의 한 숟갈 | 선택한 무드에 맞는 짧은 문구 |

## 무드별 분위기

- 차분하게: 녹색 화면, 잔잔한 화음, 느긋한 한마디
- 신나게: 오렌지 화면, 가벼운 리듬, 밝은 한마디
- 집중해서: 푸른 화면, 일정한 음, 차근차근 이어가는 한마디

## 사용 흐름

1. 웹앱을 연다.
2. 오늘의 기분을 고른다.
3. 라디오를 켜고 볼륨을 조절한다.
4. 필요한 조리 시간을 직접 설정한다.
5. 타이머가 끝나면 요리 상태를 확인한다.

## 현재 구현 범위

화면, 기분 선택, 합성 배경음, 단일 타이머, 짧은 문구 전환을 브라우저에서 구현했다. 시간은 사용자가 직접 입력한다.

## 확인할 동작

- 기분을 바꾸면 화면 색감과 스테이션이 함께 바뀐다.
- 재생을 누르면 소리가 켜지고, 정지를 누르면 멈춘다.
- 타이머를 일시정지한 뒤 남은 시간부터 이어갈 수 있다.
- 화면을 잠시 벗어나도 실제 경과 시간으로 남은 시간을 계산한다.
- 휴대폰에서 버튼과 문구를 편하게 볼 수 있다.
